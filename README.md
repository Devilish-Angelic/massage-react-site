# Тихая сила — сайт студии массажа

Простой адаптивный сайт на React + Vite.

## Запуск

1. Установите Node.js (LTS).
2. Распакуйте архив и откройте папку проекта в терминале.
3. Выполните:

```bash
npm install
npm run dev
```

4. Откройте адрес, который покажет Vite (обычно http://localhost:5173).

Для production-сборки: `npm run build`.

## Что реализовано

- Адаптивная главная страница студии массажа.
- Бегунок плавно меняет сразу три основных цветовых роли: основной, дополнительный и акцентный цвет; фон и текст также подстраиваются для контраста.
- Поиск по услугам и текстам: поиск по вхождению, а также допуск одной опечатки (замена, пропуск, лишняя буква или перестановка соседних букв). Например, `Мессаж` найдёт `Массаж`.
- Форма записи с демонстрационным подтверждением.

## Что заменить перед публикацией

В `src/main.jsx` замените демонстрационные адрес, телефон, цены и описания на реальные. Форма пока работает только на стороне браузера: для получения заявок подключите backend или сервис форм.
